# Bug Report Template

- **Bug ID:** BUG-YYYYMMDD-XX
- **Title:** Brief title describing defect
- **Date Discovered:** YYYY-MM-DD
- **Severity:** [Critical | High | Medium | Low]
- **Priority:** [P0 | P1 | P2 | P3]
- **Affected Component:** [Network | Parser | Concurrency | Balancer | Health | Proxy | Metrics]
- **Environment:** OS, Compiler, Build Preset
- **Description:** Clear summary of observed vs expected behavior.
- **Steps to Reproduce:**
  1. ...
  2. ...
- **Root Cause Analysis:** Explanation of why defect occurred at systems/code level.
- **Fix Implemented:** Technical resolution details and code change references.
- **Regression Test Reference:** Test name in `tests/regression/` or unit test suite.
- **Status:** [Open | In Progress | Resolved | Closed]
